## Changelog

### v0.22.0 beta

#### Added
- Renamed **Main Menu** to **Translate .xml Files**.
- Added a new **Translate modinfo.json** tab between **Translate .xml Files** and **Languages**.
- Added support for opening and translating multilingual `modinfo.json` files.
- Added a selectable **Source Language** for `modinfo.json` processing.
- Target languages for `modinfo.json` are taken directly from the languages selected in the **Languages** tab.
- Added a source-text preview and progress/status display for `modinfo.json` processing.
- Added an explanatory note in the **Translate modinfo.json** tab describing the special handling of `Category`, `ModName`, and `Description`.
- `modinfo.json` translation output is saved as `modinfo_translated.json`, leaving the original file unchanged.
